# Alex's Boba Drop Information
*Tell us more about your project below and how you built it!*
-----------------------------------------------------------


I figured out how to make the font Papyrus by looking up default HTML fonts,
and editing the "font-family" of style.css, and
I made the background color of the website app
go farther down instead of stopping at the last element by using invisible unicode characters

 "⠀" (U+2800)  BRAILLE PATTERN BLANK

 and incasing them in "	<p>⠀</p> " paragraph tags.

 There's probably a better way to do it, and I'm sure that someone will tell me immediately after I submit this. It's a pretty hacky way to do it, after all.

 This project took me a combined 40 minutes to learn and create.

I'm excited to work on more complicated projects and fully learn how to create websites
with HackClub!
